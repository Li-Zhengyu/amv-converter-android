# AMV 转换器 v1.6

## 下载

- [AMV-Converter-1.6.apk](../../releases/download/v1.6/AMV-Converter-1.6.apk)（约 620 KB）

## 本次更新

### 亚克力动态背景

- 主界面底层循环播放**轻度高斯模糊的动态壁纸**，卡片与按钮改为半透明亚克力材质。
- 模糊预先烘焙进 960×540 / 30fps / 静音的循环视频（约 420 KB），运行时只做 GPU 缩放与居中裁剪：
  **不占用 UI 线程，滚动不掉帧**；视频按原始比例裁剪，手机和平板都不会被拉伸变形。
- 背景播放随页面生命周期暂停/恢复，退到后台不再耗电。

### 浅色 / 深色模式

- 跟随系统深/浅色自动切换：`values` 浅色（Win11 light，白底半透明卡片）、
  `values-night` 深色（与 B站视频下载器 桌面项目同一套色板）。
- 状态栏、导航栏与图标颜色同步切换。

### 平板适配

- 屏幕宽度 ≥ 600dp 时，内容列限制为 720dp 并居中显示，避免大屏上内容被拉得过宽。

### 悬浮窗（延续 v1.5）

- 紧凑尺寸 168dp，整卡可拖动，松手自动吸附屏幕左右边缘（200ms 动画），位置记忆。

## 说明

- 支持 Android 5.0+；转换本身不需要任何权限，浮窗为可选权限。
- 纯 Java 实现，无 FFmpeg、无第三方依赖，全程离线。
