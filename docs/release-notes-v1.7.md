# AMV 转换器 v1.7

## 下载

- [AMV-Converter-1.7.apk](../../releases/download/v1.7/AMV-Converter-1.7.apk)（约 1.7 MB）

## 本次修复

### 浅色模式现在会真正跟随系统

- 之前 `MainActivity` / `PlayerActivity` 的 `configChanges` 里包含 `uiMode`，系统切换深浅色时
  Activity 不重建，主题资源也就不会重新解析，界面会一直停在旧配色。
- 已移除该项：在系统设置里切换「深色 / 浅色」后，界面会立即重建并应用对应主题，
  状态栏图标也同步反色。

### 背景不再糊、画面中心对准屏幕中心

- 此前 `TextureView` 默认会把视频拉伸填满，而代码又在拉伸基础上做了一次以左上角为轴心的额外
  缩放，结果画面既被放大裁偏，又因为放大过度显得很糊。
- 现在按 `max(scaleX, scaleY)` 计算校正系数、以视图中心为轴心做**居中裁剪**：画面中心即屏幕
  中心，比例不变形。
- 背景素材从 960×540 提升到 **1920×1080**，高斯模糊从 σ7 降到 σ2.5，竖屏裁切后依旧清晰；
  仍为 30fps 静音循环，只是 GPU 采样，UI 线程不参与。

### 其它

- 深/浅两套亚克力配色、平板居中布局、悬浮窗自动贴边等沿用 v1.6。

## 说明

- 支持 Android 5.0+；转换本身不需要任何权限，浮窗为可选权限。
- 纯 Java 实现，无 FFmpeg、无第三方依赖，全程离线。
