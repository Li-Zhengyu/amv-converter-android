# AMV 转换器 · 使用说明

## 一、安装

APK：`dist/AMV-Converter-1.3.apk`（约 170 KB）

1. 把 APK 传到手机（微信/QQ 传文件、数据线复制、网盘都行）
2. 用手机的文件管理器点击 APK 安装
3. 如果提示"禁止安装未知来源应用"，按提示允许一次即可
4. 支持 **Android 5.0 及以上**，32 位/64 位、各种 CPU 都能装（纯 Java，无原生库）

## 二、四步完成转换

### 1. 选文件
点「**选择文件**」，可以选：
- **视频**：MP4、MKV、WebM、AVI、MOV、3GP、TS 等（能不能选、能不能播取决于手机自带的解码器）
- **GIF 动图**
- **图片**：JPG / PNG / WebP（会生成 30 秒的静态 AMV）
- **音乐**：MP3 / M4A / WAV / FLAC（自动生成标题封面，用来做"音乐 MV"）

> **可以多选**：一次选多个文件会自动进入**批量模式**，见第五节。

### 2. 看一下（预览）
上面的大框就是预览区：
- 视频：点「**播放**」就能直接看，想剪哪段就播到那里
- GIF / 图片：直接显示首帧

**裁剪片段**：播到想要的位置 → 点「**设为起点**」；再播到结束位置 → 点「**设为终点**」。
点下面那行"片段：…"可以一键清除，恢复整段转换。

> 为什么要裁剪？AMV 的体积是**格式锁死的**（压缩率由播放器固件里固定的量化表决定，
> 无法像 MP4 那样调码率）。160x128、10 帧/秒大约每分钟 **2 MB**，
> 160x120、15 帧/秒约每分钟 3 MB。老播放器存储小，建议只转 1～3 分钟。

### 3. 选参数
| 参数 | 怎么选 |
|---|---|
| **分辨率** | 默认 **160x128**（高度是 16 的倍数，兼容性最稳，且是实测可播放的组合）。存储紧张选 **96x64**；大屏播放器可选 320x240。**160x120** 最经典，但高度 120 不是 16 的倍数，个别设备会挑 |
| **帧率** | 默认 **10**。想体积小就用 10，想更流畅用 15～25 |
| **画面** | 默认**拉伸**（与实测可用命令一致）；不想变形选「适应」（留黑边）；想填满又不变形选「裁剪」（会切掉边缘） |
| **体积** | **标准**是该格式的最佳画质点；"省空间/最小"让编码器量化更粗（清晰度略降、文件更小） |

下面会实时显示**预计体积**。选到实测推荐组合时会标注「已实测可播放」。

### 4. 开始转换
点「**开始转换**」：
- 进度条 + 已处理帧数 + 已生成体积
- 下方小图是**真正编码后的画面**（按播放器的方式还原出来的），可确认效果没问题
- 想中断就点「**停止**」

转换完成后：
- 自动保存（保存位置见第六节）
- 点「**播放效果**」用内置播放器直接看结果
- 点「**另存为**」存到任意位置，「**分享**」发到微信/QQ 等

## 三、内置 AMV 播放器

安卓系统本身**不能播放 AMV**，所以 App 自带一个：

- 主界面右上角「**播放 AMV**」→ 选一个 `.amv` 文件即可播放
- 转换完成后点「**播放效果**」直接看结果
- 支持 **播放 / 暂停 / 上一帧 / 下一帧 / 拖动进度条定位**
- **在文件管理器或分享里点 `.amv` 文件，可以选择用本 App 打开**（系统"打开方式"）

## 四、把 AMV 放进播放器

1. 用数据线把手机连电脑，或把 TF 卡插读卡器
2. 把保存目录里的 `.amv` 文件复制到播放器的存储卡里
3. 在播放器的"视频"菜单里找到它即可播放

也可以用「分享」发到微信/QQ，再从电脑转存到播放器。

## 五、批量转换

一次选**多个文件**就会自动进入批量模式：

- 显示文件列表，每条右侧是状态：等待 / 百分比 / 完成体积 / 失败
- 分辨率、帧率、画面、体积**统一应用**到所有文件；批量模式**不裁剪**（每个文件整段转换）
- 进度条显示总进度，下方显示"第 N/M 个"
- 结束后汇总：成功几个、失败几个、共多大，失败原因逐条列出
- 点「清空」回到单文件模式

> **怎么多选？** 系统文件选择器默认是单选，**长按任意一个文件**才会进入多选模式，
> 然后继续点其它文件，最后点「打开」。
> App 首次打开选择器时会弹一次操作说明，选文件卡片下方也有常驻提示可随时点开看。

**转换期间可以随意离开**：切到小窗、分屏、退回桌面、息屏都**不会中断**转换，
下拉通知栏能看到进度（带「停止」按钮），回到 App 会自动接上正在跑的任务。

## 六、文件保存位置

App 会**依次尝试**下列位置，保证一定存得下来，并在界面上告诉你实际存到了哪里：

1. **影片/AMV/**（安卓 10 及以上，不需要任何权限）
2. **Download/AMV/**（系统拒绝上一个位置时）
3. **公共 Movies/AMV/**（安卓 9 及以下，需要存储权限，App 会主动申请）
4. **App 私有目录**（都不行时兜底，用「另存为」可导出到任意位置）

> 若看到"媒体库拒绝写入…已存到应用目录"，说明你的系统对非标准视频格式比较严格，
> 这不影响文件本身，用「另存为」导出即可。

## 七、常见问题

**Q：为什么不能像 MP4 那样调画质？**
A：AMV 的量化表写死在播放器固件里，编码端只能匹配它。所以画质只能靠**分辨率**和**帧率**调节，
这也是所有 AMV 文件看起来画质都差不多的原因。

**Q：转换速度能多快？**
A：转换结束后进度条下方会显示**分段耗时**（总耗时、处理帧率、解码耗时、取帧拷贝耗时、
其余为缩放编码等）和**所用解码器名**。如果"解码"占了绝大部分，说明手机在用软解码；
如果"其余"占比高，可以降低分辨率或帧率。

**Q：旧版提示"转换完成，但自动保存失败"？**
A：v1.1 已修。旧版在保存失败时吞掉了真实原因。现在会依次尝试 4 个位置，并如实报告
落在哪里、失败原因是什么。

**Q：转换失败或中途卡住？**
A：多数是源文件的编码手机解不了。可以：①换个源文件；②用系统相册先转成 MP4；③缩短片段。
界面会显示具体错误。

**Q：转出来的画面上下颠倒了？**
A：**v1.2 已修**。AMV 格式规定画面"倒着存"、由播放器翻回来，而 App 内重构画面用的系统 JPEG
解码器并不知道这个约定，所以 v1.1 的**预览与内置播放器**显示是倒的
（**转换出来的文件本身一直是对的**）。若在用 v1.1 或更早，请升级。
如果升级后**真实播放器**上仍然倒置，请反馈 —— 那说明该设备不遵循 AMV 的翻转约定。

**Q：画面左右也颠倒？**
A：不会。实测**仅用垂直翻转**就能与源画面吻合到 45.4 dB（若还左右翻了不可能达到这个值），
所以只存在上下翻转问题，没有左右翻转。

**Q：文件很大？**
A：格式限制，见上式。降低分辨率（160x128 → 96x64 约省 70%）、降低帧率、缩短片段。

**Q：想反馈问题？**
A：界面上的错误文字 + logcat 里 `AmvSelfTest`、`MediaVideoSource`、`AmvPlayer`、`OutputSaver`
标签的日志都会很有帮助。App 启动时会自检编码核心，失败会打 `AmvSelfTest: FAIL: ...`。

## 八、隐私

转换**完全在手机本地进行**，不联网、不上传、不需要任何存储权限（安卓 10 及以上；
安卓 9 及以下只在保存文件时请求一次存储权限）。选文件用的是系统文件选择器，
软件只能读到你**主动挑选的文件**。
